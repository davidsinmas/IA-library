# Pruebas rápidas

1. Crear un entorno virtual e instalar `requirements.txt`.
2. Ejecutar `python app.py`.
3. Comprobar que aparecen los recursos de `resources/`.
4. Seleccionar un recurso, modificarlo y guardarlo.
5. Comprobar la copia al portapapeles.
6. Configurar una API key válida y probar el diálogo IA.
7. Ejecutar `build_portable.bat` en Windows y comprobar `dist/IA-Library.exe`.
